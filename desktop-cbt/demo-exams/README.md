# Imagemakers CBT demo exam files

This folder is generated during the Windows release build and included in the downloadable ZIP beside the Windows installer.

It contains 18 signed `.imexam` packages:
- Primary 1, Primary 2 and Primary 3
- Ruby and Sapphire arms
- Mathematics, English and Basic Science
- Eight objective questions per exam
- Ten-minute demo duration

Demo candidate admission numbers use this pattern:
- `DEMO-P1-R-001` through `DEMO-P1-R-004` — Primary 1, Ruby
- `DEMO-P1-S-001` through `DEMO-P1-S-004` — Primary 1, Sapphire
- Replace `P1` with `P2` or `P3` for Primary 2 or Primary 3

The four demo names are Ada Okafor, Daniel Bello, Mary James and Samuel Musa. The same four names are repeated for each class and arm.

## Importing a demo

1. Install and open Imagemakers CBT.
2. Open **Supervisor controls**.
3. Select **Import signed package** and choose a file from this folder.
4. Select the imported exam, set it as the active exam, then return to the station overview.
5. Start a demo using the matching admission number and registered name.

The application also seeds the same 18 demo exams automatically on a fresh local database, so manual import is optional. Demo attempts are clearly marked and are never uploaded to the school system.

These are public practice packages. Their demo answer keys are not confidential and must never be reused for a real examination.
